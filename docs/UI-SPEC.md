# Meeting Intelligence 原生界面约定

## 已确认要求

- 使用 Apple 提供的 macOS 26+ 原生 UI，SwiftUI 为主，必要时使用 AppKit。
- 以用户提供的 Figma 原型作为布局、视觉和交互参考，保留其主要结构与风格。
- 产品名统一为 Meeting Intelligence，移除播放器右上角的“高清音质”标签。
- 应用图标沿用侧栏的灰底波形标志；提供多分辨率 `.icns`，启动时显式更新 Dock 图标，构建后刷新该应用的 LaunchServices 注册。
- 新录制与回放按钮使用黑底白字；最近会议的选中背景为灰色，回放进度条为黑色，不跟随系统蓝色强调色。
- 设置在主窗口内导航，录音和 transcript 保存目录可独立配置；后续增加云端 API 设置。
- 保持最小开发环境，不为设计参考安装前端依赖。

## 布局与原生组件映射

| 设计区域 | 原生实现方向 |
| --- | --- |
| 左侧品牌、新录制、最近会议、设置 | NavigationSplitView 的 sidebar，使用原生 List 与 Button；品牌完整显示，必要时自然换行。 |
| 窗口红黄绿按钮 | 使用 macOS 系统窗口控制，不绘制原型中的装饰按钮。 |
| 会议标题、导出、更多 | 原生窗口标题与 toolbar、Button、Menu；遵循 macOS 26 系统材质和控件反馈。 |
| 录音播放卡片 | SwiftUI 布局、原生播放按钮及可键盘操作的 Slider；波形可用 Canvas 绘制并连接实际音频数据。 |
| 字幕列表 | SwiftUI 列表或滚动容器，保留头像/来源标识、时间戳、正文和当前播放行高亮。 |
| 点击字幕回听 | 原生 Button/可访问操作调用统一播放器 seek；播放时按时间区间更新高亮。 |
| 录制页面 | 保留计时、麦克风图标、实时波形、实时字幕和结束按钮的位置关系；使用实际采集状态。 |

沿用原型的浅色背景、简洁黑灰层级、圆角、细分隔线和红色录音强调色；使用系统字体与 SF Symbols。按系统可用空间和字号适配，不把网页的固定像素尺寸照搬为窗口约束。Liquid Glass 以系统导航和控件默认行为为主，不在正文、字幕和播放器上叠加不必要的材质。

## 原型与真实功能的边界

原型以定时器模拟播放与录音，字幕、会议、波形、说话人及摘要都是演示内容，没有实际音频采集、ASR 或持久化。它确认设计方向，不等于这些功能已完成。

- 会议摘要、笔记、导出和设置入口已出现在设计中；保留设计参考，具体可用功能随对应阶段交付，不因原型中有按钮就视为首版功能已确认。
- 首版不能自动显示虚构姓名或“3 位发言人”；未实现说话人识别时显示应用音频/麦克风来源，后续再映射真实说话人信息。
- 原型的“26 分钟”与模拟播放器 142 秒不一致；真实实现统一从音频资产读取时长。
- “自动保存中”等状态只能在实际持久化已接入后显示。

## 原生 UI 验收

1. 回听页与录制页保持参考设计的主要信息层级；导航、窗口、工具栏和交互控件使用原生实现。
2. 所有面向用户的产品名称为 Meeting Intelligence，不出现“高清音质”标签。
3. 英文名称在默认窗口与窄侧栏内不裁切、不覆盖按钮。
4. 播放、暂停、字幕定位、滚动跟随与键盘焦点行为一致，VoiceOver 能读出按钮用途与播放状态。
5. 在真实 macOS 应用中验证布局、浅色/深色外观和窗口缩放；2026-11-15 已启动原生应用并检查默认浅色主窗口和设置入口；深色、窄窗口、录制与回听页仍需继续验收。

## 录音与转写交互（2026-11-15）

新录制页仅提供麦克风与本地转写开关；语言和模型资源管理只在设置页。默认使用中文，启动时自动准备 Apple 系统语音资源，不在应用包重复分发模型。录制页分别显示应用和麦克风输入状态，字幕约每 10 秒更新，可关闭“跟随最新”。历史页显示识别状态和来源，支持继续/暂停转写、点击字幕回听与灰色播放高亮，双轨会议可选择混听或单轨。模型和识别错误单独显示，不替代音频保存状态。

侧栏品牌、新录制、分组标题、会议内容与设置采用统一水平基准。会议名限制一行、尾部省略，悬停显示全名，文字宽度由侧栏约束而不是标题长度决定。垂直滚动条使用 4 pt 淡灰悬浮滑块，无轨道底色，保留原生拖动和滚轮操作。

## 历史详情与云端处理（2026-11-17）

历史详情使用原生分段选择器在“字幕”和“会议摘要”间切换。两页正文占用剩余可用高度并独立滚动；长摘要不再放在固定头部的展开区域中。底部播放条保持可见，字幕页保留跟随播放与定位操作，转写用量等详情放在字幕的滚动区域。录制中的实时字幕维持原有布局。

会后云端精校使用最多 3 个片段的滚动并发队列，逐片持久化 task ID 和结果，按原始会议时间线展示。失败时停止派发新片段，等待已在处理的片段保存结果；暂停取消本机处理，继续时复用已有 task ID，已完成片段不重复上传。

播放条在记录详情页始终固定于底部，未加载回放记录时显示空状态并禁用播放和定位。在新录制、录制中和设置页隐藏；进入详情时从底部弹簧升起，离开时向下滑出并释放布局空间，切换记录详情不重复进出动画。遵循系统“减少动态效果”设置，仅淡入淡出。隐藏不改变当前回放。播放条独立于当前浏览记录；切换记录、新录制页和设置页不切换或暂停回放。详情页增加“播放此记录／暂停此记录”，明确点击才加载对应音频；点击字幕也显式切换到所属记录并定位。空格控制当前播放条，左右键根据正在回放记录的字幕跳句，文字输入和弹窗期间不拦截。仅所属记录的字幕显示回放高亮并跟随滚动。点击播放条标题返回所属记录。开始录音时暂停回放，录音结束不更换回放记录；删除当前回放记录时播放条恢复空状态，删除其他记录不影响回放。

上下方向键按侧栏顺序切换相邻记录详情，不触发播放、不切换回放音频、不改变播放进度或暂停状态。到达首尾后保持当前记录，不循环。新录制和设置页、录制中、重命名输入和弹窗期间不拦截；侧栏随选中记录滚动。
